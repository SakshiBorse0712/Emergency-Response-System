# 🚑 Emergency Response System

A full-stack **Emergency Response System** that connects **Patients, Ambulances, and Hospitals** to provide faster emergency assistance. The system helps patients request emergency services, finds the nearest available ambulance and hospital, and enables real-time status tracking.

---

## 📌 Features

### 👤 Patient

* Register and log in securely
* Send emergency (SOS) requests
* Share current location
* Track emergency request status
* View assigned ambulance and hospital

### 🚑 Ambulance

* View assigned emergency requests
* Accept or reject requests
* Update live location
* Change availability status

### 🏥 Hospital

* Manage hospital profile
* Update available beds and ICU capacity
* Receive emergency notifications
* Monitor incoming patients

### 👨‍💼 Admin

* Manage users
* Manage hospitals
* Manage ambulances
* Monitor all emergency requests
* View system dashboard

---

## 🛠️ Tech Stack

### Frontend

* React.js
* Vite
* Tailwind CSS
* React Router
* Axios

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT Authentication

### Real-Time Communication

* Socket.IO

### Database

* MongoDB Atlas / MongoDB Community Server

---

## 📂 Project Structure

```text
Emergency-Response-System/
│
├── client/                 # React Frontend
│   ├── src/
│   ├── public/
│   └── package.json
│
├── server/                 # Express Backend
│   ├── controllers/
│   ├── models/
│   ├── routes/
│   ├── middleware/
│   ├── socket/
│   ├── config/
│   ├── utils/
│   └── package.json
│
└── README.md
```

---

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/SakshiBorse0712/Emergency-Response-System.git
```

```bash
cd Emergency-Response-System
```

---

### 2. Install dependencies

#### Backend

```bash
cd server
npm install
```

#### Frontend

```bash
cd ../client
npm install
```

---

### 3. Configure Environment Variables

Create a `.env` file inside the **server** folder.

Example:

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
CLIENT_URL=http://localhost:5173
```

---

### 4. Run the Backend

```bash
cd server
npm run dev
```

---

### 5. Run the Frontend

```bash
cd client
npm run dev
```

---

## 🔄 System Workflow

1. Patient logs into the application.
2. Patient sends an emergency (SOS) request.
3. Patient's location is shared with the server.
4. The system identifies the nearest available ambulance.
5. A nearby hospital receives the emergency notification.
6. Ambulance accepts the request.
7. Live updates are sent using Socket.IO.
8. Patient can monitor the emergency status in real time.
